# 编辑器 0.19：Quad→Hex 与 Beat Saber 工作台

作者默认 `iGoBeat`。修改“曲谱作者”后记住为以后新建／制作的默认作者；打开已有曲包不会覆盖记忆，也不会自动更改原署名。歌手字段与曲谱作者分开。

## Quad → Hex

在谱面设置选择 Quad 来源与 Hex 目标，点击“设置乐句并预览”。默认使用 2026-10-20 HD/Pro 原手势优先规则，替换旧的顺序单击式重新编排。

- 原滑动：默认优先还原相对位置、方向、节点时间和长度；可选择重新设计路径但保持时间，或仅保留起点点击。
- 多条滑动同起点保留代表串，完全同时间同方向合并；不同起滑时间优先保留，源交接最多短暂两串。无法安全排布会失败并给出原因，不偷偷截断。
- 早于 Hex 第28帧的滑动开头略去，后续节点不移动。
- 新增滑动：关闭／仅在原滑动稀少时少量补充／自定义最多0～35%普通点击组。实际比例由可读性决定，不强凑；原滑动与长按转换不占补滑配额。
- 新设计滑动3／4／5帧，推荐5帧；原滑动保留原间隔。
- 长按默认保留长度，可尽量转滑或只保留起点。转滑放不下时保留可读长按并记录。
- 奖励按原时间、相对原位还原并减少过密，可进一步减少或关闭。
- 点击可选择贴近原位、平衡、更多图案。多押改单押，重复节奏复用动作主题。
- 所有选项自动记住。与当前规则冲突的旧两手／强制双押／随机散点选项不再出现在此入口。反向准确互转及手动制谱保留。

可生成当前目标或“全部对应难度”；缺少 Quad 源档位时跳过，保留原目标。先看预览、明细，再应用。单档沿用撤销；整批用工具栏“撤销整批”。保存才更新原 `.igb`。整批撤销只保留本次会话最近一次，打开另一首歌后清除。

## Beat Saber 四玩法工作台

工具栏“Beat Saber”打开专用面板。支持原歌曲目录、ZIP、合集目录，以及带 `beatsaber-original` 的编辑器曲包。旧工程只有扁平节奏信息时，需要重新选原曲包。

1. 添加来源，查看自动对应来源难度、Arc／Chain数量、缺档替代和错误。相同音频在本次扫描内自动去重。
2. 勾选歌曲、玩法和难度。默认11谱：Hex三档、Quad三档、Piano普通／困难、Fall三档。
3. 填曲谱作者、可选批次标识；完整MP3选择192／256kbps，封面最长边256／512。
4. 选择成品目录并生成。每次只处理一首音乐，输出独立 `.igb`，不自动改原曲库或上传。新包默认免费，已携带的VIP元数据保留。
5. 点击歌名查看结果，打开成品试听／编辑。同UUID当前歌曲还可选择应用已生成且仍勾选的难度；不替换当前媒体，支持整批撤销。

生成采用当前认可规则：

| 玩法 | 制作方法 |
|---|---|
| Quad | 原谱重复节奏、全部20格、连续避重、多种组合；Easy单押为主少双，Normal无四押，Hard双三为主少四，逐首难度不倒挂；Arc滑动5帧，Chain足长长按 |
| Hex | 从最终对应Quad生成节奏动作图案；三档单操作，5帧连续斜扫／折线／S形；Arc及Chain按持续长度转滑，保留来源审计 |
| Piano | Beat Saber Easy→Normal、Normal→Hard；少量2～4押 |
| Fall | 红左蓝右4／5／6轨，1／2／3操作；长按仅两端，滑动至少6帧 |

网格律动通过现有本地 htdemucs 分离鼓组，再检测低音鼓瞬态生成；所有模型随App携带，不联网下载。原Info／原难度JSON、源作者、设计及验证明细随包保存。Quad改变后，已生成Hex会标记需要更新，不静默改谱。

取消会保留已完成成品，清理当前周转目录。相同设置和来源重试复用已核对摘要的结果；设置变化生成新命名文件，不覆盖已有成品。逐首失败不阻止后续歌曲，可只勾选失败项重试。请自行选定满意的版本后清理不需要的成品。

当前支持 Info.dat 2.x、谱面数据2.x／3.x；优先Standard对应难度，缺档采用最近可用档并报告。已知视觉扩展可忽略装饰／假音符，未知玩法或数据版本明确报错。需要人工试听确认手感，自动校验不代替逐曲听审。

批次文本目前写入曲包描述；服务器下载分类仍由发行目录的 `batch`／`tags` 设置，工作台不自动发布服务器分类。

## 0.19.1 转换排错

选择失败的歌曲可展开完整错误；成品目录保存对应 UUID 的 `.failure.json`（包含源路径、请求和工作日志），重试成功后自动移除。密集 Hex 原排布失败时尝试有限后续落点搜索，仍执行原可读性与单手约束。MMA2 `_BPMChanges` 仅作为编辑器网格信息记录，不改变真实音符时间；真实变速读取 v2 `_events` type=100 的 `_floatValue` 或 v3 `bpmEvents`。
