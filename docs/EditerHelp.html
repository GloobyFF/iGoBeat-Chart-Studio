01

下载后，直接打开

支持的电脑

搭载 Apple 芯片（M1 或更新）的 Mac，macOS 14 或更新系统。当前下载不适用于 Intel Mac、Windows 或 iPhone。

内含 Python、分轨与节拍模型，无需另装 Xcode、Python 或命令行环境。解压后约 1.2GB；整曲分轨还会生成音频缓存，请预留数 GB 可用空间。

安装步骤

  1. 下载 ZIP 并双击解压。
  2. 把 iGoBeat Chart Studio.app 拖到“应用程序”。
  3. 双击启动，点“打开 / 新建”开始。

这是尚未 Developer ID 公证的测试版。如果首次被系统阻止，请在核对来源后，到“系统设置 → 隐私与安全性”选择“仍要打开”。无需关闭系统安全保护。

本版供非商业制作与测试使用。最高精度所含 madmom 模型采用 CC BY-NC-SA 4.0；商业使用须另行取得相应授权。第三方许可与版本清单随下载包提供。查看版本与校验值。

02

先完成第一张谱

  1. 打开音乐或曲包。点击“打开 / 新建”，选 MP3、WAV、OGG、M4A、FLAC，或已有 .igb。也可以把文件拖进窗口。
  2. 选择一个槽位。在“谱面总览”中选 Quad / Hex / Piano / Fall 与简单 / 普通 / 困难。建议第一次用 Quad 普通。
  3. 暂停并定位。按空格播放，听到想放音符的地方暂停；点击波形或用左右箭头微调时间。
  4. 放一个普通音符。点右侧普通音符图标，再点棋盘格。播放试听，拖动音符调整位置。
  5. 保存为 .igb。按 ⌘S，填写难度等级并选择文件名。之后继续打开这个文件修改即可。
03

左边听音乐，右边看谱面

调整布局

拖动中间分隔条调整左右宽度，双击恢复默认。棋盘保持比例。左侧工具按可用宽度自动排列，可用“波形 / 音乐分析 / 谱面设置 / 音乐制谱”快速跳转。

理解时间线

黄色是当前播放时间，白线是 BPM 参考拍线，不是保证准确的鼓点。有分轨分析时，青色/粉红/橙色/紫色分别显示鼓、人声、低音、其他伴奏；导入原谱时，绿色用于原谱节奏对照。

“仅在最佳点显示”只显示音符最佳打击时刻那一帧，用于对拍；正常编辑时建议先关闭。

04

用鼠标直接制作音符

普通与奖励

暂停到目标时间，点击对应图标，再点击棋盘。点已有音符选中，左键拖动可换格；选中后可通过类型工具或“音符数值编辑”修改种类与打击时间。

长按

选择长按图标并放置，在波形下方“编辑轨”找到这颗音符的时长条，拖动右侧尾点调长度。也可在“音符数值编辑”输入持续秒数；“完整显示”可把头尾放进同一视野。

滑动与转弯

选择滑动工具，依次点起点、转弯点和终点，或拖动绘制路线；按 Enter 完成，Esc 取消。编辑器按相邻格补路，新节点默认间隔 3 帧。

选中后可以拖动某个节点，自动补上连接路径并延长后续时间；整组移动使用位置调整工具。已有整串可在“滑动间隔”整理为统一 3 或 4 帧，失败的串保留并给出结果。

删除与冲突

切换删除工具后点击，或对音符右键删除；滑动删除按整串处理。⌘Z 撤销。手动放置时红框提示可能重叠，仍需试听检查；部分自动补路和批量操作有结构与范围校验，不能把红框视为完整可玩性审核。

Fall 当前只支持生成和预览，不支持在棋盘上逐音符编辑。Quad 滑动期间尽量不要安排其他按压；Hex 滑动避免短距离折返和小三角形。位置要服务于乐句，别让自动生成代替试听。

05

把鼓点和人声分开看

  1. 打开“高级音乐分析”，选择标准、精细或最高精度，点击“分析整首音乐”。
  2. 完成后通过播放条的“试听”选择原曲或独立声部，位置保持同步。
  3. 选中希望参与生成的声部，比较起音竖线与听到的节奏；按需手动修正。

三种精度

标准：先做快速参考。
精细：增加分离重叠和推理次数。
最高精度：htdemucs 分轨 + madmom 神经网络起音与节拍跟踪，CPU 计算更慢。

分析结果的含义

人声分离不是歌词转写，也不保证每个字都有准确落点。白线是 BPM 参考，彩色线是分析建议。复杂和声、混响、弱起与变速需要听审。

“分析网格律动”只生成背景闪烁强弱，不改音符。分析可取消；当前高级分析单首上限 20 分钟。

06

设定规则，再生成草稿

  1. 选中目标槽位。原创音乐制谱目前支持 Quad 与 Hex；Piano / Fall 使用谱面转换。
  2. 选择节奏来源。可以用当前音乐、当前谱面或导入的 Beat Saber / osu! 原谱。参考强度有音乐优先、均衡参考、谱面优先、仅谱面节奏；前三种需要先完成高级分析。
  3. 选择规则。按当前模式设置最多同时按压数、滑动多少、是否保留长按与奖励、顶行与避让等。不同玩法可选项不同。
  4. 先预览、再应用。试听整齐程度和手部移动。目标已有谱面时会提示覆盖；确认后写入当前槽位，其他槽位保留。应用后可撤销，保存后才写入 .igb。
07

一首歌，多种玩法

来源怎样使用
.igb直接打开，同一个歌曲包内的 12 个玩法/难度槽位对应加载。
Beat Saber打开单首 ZIP 或文件夹，选择支持的原谱难度。保留原谱节奏供编排参考；不把原游戏灯光直接等同于 iGoBeat 网格律动。
osu!打开 .osz 或单曲目录。标准模式可旋转映射到 Hex；Mania 通常适合 Fall。不同来源支持范围以导入提示为准。
旧 iGoBeat打开单曲文件夹、plist 或 ZIP。旧 Quad 的简单/普通/困难映射到对应槽位，原始导入不自动统一滑动速度。

在“谱面转换”选择来源、目标模式和目标难度。Quad ↔ Hex 可使用相对位置映射；Quad → Hex 也可选“按乐句重新编排”，设置单手、斜向、同向换线、路线间距等。两种方式不能同时使用。已有目标在应用前确认覆盖；无法转换的部分按选项跳过或改成普通音符，并在结果中报告。

08

统一调整一段，或整张谱

波形下方“显示范围”旁的 批量时间 按钮开启后会高亮。可以选择整张谱、输入起止时间，或在时间轴框选；⌘ 点击也能多选。选到滑动节点会扩展为整串。

输入正负帧数或毫秒，查看预览并循环试听，然后点击“应用”。整体偏移保留长按长度和滑动原有间隔，不移动音乐；一次撤销即可恢复。本工具一次只处理当前槽位。

09

一个 .igb，就是一首作品

保存 / 另存为

⌘S 保存，⇧⌘S 另存为。第一次选择名称和位置，之后写回同一文件。所有玩法和难度、音乐、封面、可携带的分析数据放在同一个包中。

难度等级可填 1～255，留空按简单 3、普通 6、困难 9。保存不强制启动音乐分析；已有网格律动会保留。

关闭时由你决定

保存：写回 .igb；新歌先选位置。
放弃所有修改：保留上次保存的文件，丢弃本次未保存的编辑草稿；新建未保存的作品将放弃。
取消：回到编辑器继续操作。

后台分析会先取消并收尾；真实文件写入期间需要等待完成，避免留下损坏的包。

安装版工作与分析缓存：~/Library/Application Support/iGoBeat Chart Studio/Workspace。从“文件位置”可直接打开，不必寻找随机编号文件夹。已保存作品以你选择的 .igb 路径为准；旧文件备份保存在工作目录的 PackageBackups 中。

常用快捷键

空格播放 / 暂停；歌名等文字输入框仍允许输入空格。
← →逐帧定位，谱面基准为 30 FPS。
⌘O / ⌘S / ⇧⌘S打开 / 保存 / 另存为。
⌘Z撤销当前编辑操作。
Enter / Esc完成滑动 / 取消当前绘制或预览。
鼠标右键 / Delete删除音符；滑动按整串处理。

手机内的曲谱编辑器

上面的截图与高级分轨操作属于 Mac 版。手机编辑器复用游戏素材与触控界面，不能把 Mac 的 htdemucs / madmom 四分轨功能理解为手机也已内置。
  1. 从首页进入编辑入口，通过系统文件导入或 App 的共享文稿添加自己的音乐 / 曲包。
  2. 选择创建新谱或继续编辑，再选歌曲、玩法和难度。编辑列表使用本地制作文稿，不是下载中心曲库。
  3. 用播放、暂停、前后帧与网格操作定位节拍；通过音符类型和修改音符入口调整内容。
  4. “曲谱助手”可做本地节奏分析与谱面转换；先检查生成结果，再手动修正。
  5. 完成后保存 / 导出 .igb，转移到 Mac 继续制作或导入游戏验证。最终操作以手机当前界面为准。

Mac 的试打主要帮助检查时间与位置，不替代手机上的多触点手感验收。作品完成后，建议在实际游玩设备测试整首。

分轨试听与保存

完成高级音乐分析后，在播放条的“试听”菜单选择人声、鼓、低音或其他伴奏。切换声部会保留播放位置、速度与播放状态。保存 .igb 时会携带压缩试听分轨，重新打开或换一台 Mac 仍可试听。旧曲包如果只有分析结果、没有分轨音频，需要重新分析；不会用原曲冒充声部。

常见问题

蓝色、粉色的线一定是准确节拍吗？

不是。它们是鼓点、人声等声部的起音估计。通过独立声部试听、BPM 参考和手动调整共同校准；尤其不要把人声起音当成逐字歌词标注。

为什么分析很慢？能取消吗？

最高精度需要多次 CPU 分轨推理，长曲可能耗时较久。先用标准精度完成草稿，确有需要再提升精度。处理中可以点击“取消处理”；重复分析相同音频和参数会使用缓存。

为什么 Fall 不能像 Quad 一样点击编辑？

本版 Fall 是生成与预览工作流。先从已有谱面或支持的外部谱面转换，再播放检查轨道与节奏；不提供逐格音符编辑。

改完没有保存，下一次还能恢复吗？

异常退出可能保留工作草稿，可从最近编辑中查看。主动选择“放弃所有修改”会取消当前草稿恢复；已经保存的 .igb 和保存备份不受影响。不要用恢复草稿代替正式保存。

可以在没有网络的环境使用吗？

安装包内含运行时、音乐分离模型和这份使用指南。常规编辑与本地分析可离线使用；下载应用、访问 GitHub 或网站仍需要网络。

所有 Beat Saber / osu! 文件都能导入吗？

不是。某些新版格式、Mod 时间映射或异常曲包可能不支持。请阅读导入报告，选择单首完整歌曲包；不要把包含很多首歌的总目录当作单曲。

English quick start

iGoBeat Chart Studio 0.17.1 is a native editor for Apple Silicon Macs running macOS 14+. Unzip the download, move the app to Applications, then open your audio or .igb file. The current editor UI and detailed guide are in Chinese.
